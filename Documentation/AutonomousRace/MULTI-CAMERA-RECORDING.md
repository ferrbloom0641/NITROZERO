# 카메라별 동시 녹화

1. RH_racing_Autonomous 씬을 열고 Play를 누릅니다.
2. 메뉴 Tools > Trailer > Record All Race Cameras를 엽니다.
3. 기본 1920×1080, 30fps, 30초를 확인하고 Restart + Record All Cameras를 누릅니다.
4. 레이스가 처음부터 3배속으로 시작되며, 등록된 카메라 수만큼 별도 MP4가 동시에 저장됩니다. 현재는 6개입니다.
5. 지정된 길이에 도달하면 자동 종료됩니다. 도중에 Stop Recording으로 종료할 수도 있습니다. Open Output Folder로 결과를 확인합니다.

저장 위치: NITROZERO/Recordings/Race_All_날짜_시간/. 파일명에는 컷 번호와 카메라 이름이 포함됩니다. 매번 새 폴더를 만들어 이전 촬영을 덮어쓰지 않습니다. 기본 MP4는 무음입니다.

각 파일은 동일한 레이스 시점을 담습니다. F4 코너 팬과 F6 체크포인트는 차량이 해당 지점에 도착하기 전까지 빈 도로를 담습니다. F5는 빨강을 계속 따라가며 부스터 전개 구간도 포함합니다. F3 달리는 기존 8초(3배속 영상에서 약 2.67초) 이동 후 마지막 위치를 유지합니다.

녹화 중 촬영 패널과 단축키는 잠시 숨기거나 잠급니다. Inspector에서 속도, 카메라 배열, 씬 구성 등을 바꾸지 마세요. 종료하면 패널과 카메라 대기 갱신 설정을 복원합니다. 재생 속도는 3을 유지합니다.

선택 컷의 화면을 복제하는 방식이 아니라 각 Cinemachine 컷의 최종 구도·진동을 독립 출력 카메라와 RenderTexture에 반영합니다. 추가 출력에는 Brain이 없어 기존 고속 카메라 동기화 수정과 충돌하지 않습니다. 고정 프레임 간격으로 녹화하여, 렌더링이 느릴 때는 실제 녹화 작업 시간이 길어질 수 있습니다.

검증: 별도 그래픽 테스트 씬에서 3배속·320×180·30fps·0.5초로 6개 MP4를 실제 생성했습니다. 모든 파일에서 15개 영상 프레임과 동일한 프레임 간격을 확인했습니다. 컴파일 및 종료 후 임시 출력 카메라 정리도 통과했습니다. 실제 전체 씬의 1080p 다중 렌더 성능과 최종 색감·VFX는 별도 확인이 필요합니다.
