# RH 자동 레이싱 — 시네머신 촬영 카메라 6개

씬: `Assets/01RAEHYEON/RHScenes/RH_racing_Autonomous.unity`

Hierarchy의 `RACE CINEMACHINE - 6 Race Shots` 아래에 카메라 6개와 출력 카메라가 있습니다. Play 후 Game 화면을 클릭하고 F1–F6 또는 오른쪽 촬영 패널로 컷을 선택합니다. 기본 피사체는 빨간 차량입니다.

| 키 | 카메라 | 촬영 동작 |
|---|---|---|
| F1 | CM01 - Front Pack | 선두 앞에서 6대 전체를 바라봅니다. 코너에서도 차량들이 화면에 들어오도록 거리를 조절합니다. |
| F2 | CM02 - Rear Duel | 선택 차량과 가장 가까운 경쟁 차량 두 대를 뒤쪽 사선에서 따라갑니다. 컷을 고르는 순간 상대가 고정됩니다. |
| F3 | CM03 - Side Dolly | 차량 옆에서 함께 달리며 뒤쪽 18m에서 앞쪽 18m까지 8초 동안 부드럽게 이동합니다. 끝에 도달하면 유지합니다. |
| F4 | CM04 - Corner Pan | 도로 거리 2,850m 지점 옆에 고정되어 두 차량을 따라 회전합니다. |
| F5 | CM05 - Red Engine Deployment | 빨강 뒤쪽 사선에서 실제 엔진 전개부를 바라봅니다. 피사체 선택과 관계없이 빨강 전용입니다. |
| F6 | CM06 - Overhead Checkpoint | 도로 거리 3,150m, 높이 23m의 고정 구도입니다. 위치와 시선을 유지하여 차량들이 화면을 빠르게 통과합니다. |

## 촬영 순서

1. Play 후 F1로 전체 레이싱을 확인합니다.
2. F2/F3로 경쟁과 측면 이동 컷을 촬영합니다. `Next car`로 피사체를 바꿀 수 있습니다.
3. `Replay dolly`는 주행을 유지하면서 달리 이동만 처음부터 재생합니다.
4. `Cue corner (restart race + seek)`는 **레이스를 처음부터 재계산하여** 촬영 준비 구간까지 이동시킵니다. Story Mode에서는 부스터 전개 전의 코너 진입 준비 구간, 일반 모드에서는 코너 카메라 약 230m 전방으로 이동합니다. 팬 컷도 선택됩니다. 원래 위치로 돌아가려면 왼쪽 `Restart`를 누릅니다.
5. H로 양쪽 조작 패널을 숨기거나 다시 표시합니다. 녹화에는 `Race Cinemachine Output`을 사용합니다. Unity Recorder에서 Game View를 사용할 경우 H로 UI를 숨깁니다.

F4만 누르면 주행 위치는 바뀌지 않습니다. 초반 직선에서는 코너 카메라와 차량이 멀리 떨어져 있으므로 `Cue corner`로 촬영을 준비하세요.

`Cue engine deployment (restart + seek)`는 레이스를 재계산하여 빨강 엔진 전개 직전으로 이동하고 F5를 선택합니다. `Cue checkpoint pass (restart + seek)`는 선두가 체크포인트 160m 앞에 도착한 시점으로 이동하고 F6를 선택합니다. F5/F6 키만 누르면 현재 주행 시점에서 컷만 전환합니다.

## 카메라별 진동

오른쪽 `Camera shake` 슬라이더는 전체 강도이며 기본 1, 범위 0–2입니다. 0이면 진동을 끕니다. 각 카메라의 `Race Camera Forces`에서 개별 강도와 주파수를 조절할 수 있습니다.

| 컷 | 진동 성격 |
|---|---|
| F1 전체 | 구도를 읽기 쉽도록 약한 엔진·노면 진동 |
| F2 추격 | 노면 충격과 주변 차량의 풍압 |
| F3 측면 | 옆 차량 풍압을 강조하고 다른 주파수의 노면 진동 사용 |
| F4 코너 팬 | 차체 진동 없이 차량이 가까워질 때 풍압 반응 |
| F5 엔진 | 빠른 엔진 미세 진동, 부스터 전개·수납 구간의 기계적 충격 |
| F6 체크포인트 | 평소 안정된 구도, 근접 통과 시에만 짧은 풍압 진동 |

Engine Frequency와 Wind Frequency는 시간당 진동 주파수, Road Spatial Frequency는 주행 거리당 노면 변화량입니다. Position은 미터, Rotation과 Deployment Kick은 도 단위입니다. 차량마다 위치·속도·부스터 상태를 반영하고 카메라별 노이즈 시작점도 다릅니다. 기존 진동 스크립트의 다축 Perlin 방식에 레이스 상태를 연결한 별도 컴포넌트로, 차량이나 VFX 자체를 흔들지는 않습니다. Pause 시 진동도 멈춥니다.

## 조절

각 CM 오브젝트의 `Race Cinematic Shot`에서 Offset X(측면), Y(높이), Z(전후), Aim Height, Rotation Response를 조절합니다. 구도는 재생 중 계산되므로 Transform 대신 이 값을 수정하세요. 화각은 같은 오브젝트의 Cinemachine Camera > Lens > Field Of View에서 조절합니다.

측면 달리는 Dolly Start/End/Duration, 팬은 Pan Road Distance로 조절합니다. 이 달리는 고정 스플라인 카트가 아니라 달리는 차량을 기준으로 이동하는 촬영 리그입니다. 팬은 위치가 고정되고 조준 방향만 변합니다.

루트의 Smooth Transitions를 켜면 컷 사이를 부드럽게 연결합니다. 기본은 즉시 컷 전환입니다. 기본 촬영용 세팅은 16:9 기준이며 다른 종횡비에서는 구도를 확인하세요. Play 모드에서 수정한 값은 일반 Unity 규칙에 따라 종료 시 되돌아갈 수 있습니다.

## 연결 및 검증 범위

실제 Cinemachine 3.1.7 Camera 6개와 Brain을 사용합니다. 별도 출력 채널(Channel04)로 차량 내부의 기존 가상 카메라와 분리합니다. 차량 내부 카메라와 프리팹은 보존되며, Play 동안 다른 출력 Camera/AudioListener만 일시적으로 비활성화합니다. 리그를 끄면 저장했던 활성 상태를 복원합니다.

기존 자동 주행의 단순 미리보기 카메라는 이 씬에서 생성하지 않습니다. 차량의 화면 보간이 끝난 뒤 촬영 구도를 계산하고 Brain을 갱신합니다. Pause는 달리 시간도 멈추고 Restart는 촬영 시간을 초기화합니다.

2.5–3배속에서 카메라가 앞뒤로 튀는 현상을 수정했습니다. 기존 메인 카메라는 출력 Camera가 꺼져도 모든 채널을 읽는 Cinemachine Brain이 계속 실행되어, 현재 촬영 구도가 계산되기 전에 이전 위치를 캐시하고 있었습니다. 촬영 중 다른 Brain도 잠시 끄고, 차량·바퀴 처리 이후 촬영 리그가 마지막으로 갱신되도록 했습니다. 리그를 끄면 각 Brain의 원래 활성 상태를 복원합니다. 속도 배율과 주행·부스터 시나리오는 유지합니다.

실제 Play Mode에서 2.5/3배속, 24/30/60/90fps에 해당하는 프레임 간격을 번갈아 적용하고 여섯 컷을 전환했습니다. 수정 전 카메라와 현재 컷 위치의 최대 차이는 6.944580m, 수정 후에는 0.000000m였으며 차량의 주행 거리는 역행하지 않았습니다. 검사 시 의도적인 카메라 떨림은 꺼서 위치 동기화만 분리해 측정했습니다. 결과는 `fast-playback-before.txt`, `fast-playback-validation.txt`입니다. 본 씬의 GPU 렌더 성능 측정은 포함하지 않습니다.

별도 Unity 검증 프로젝트에서 실제 도로 메시와 빨강 부스터 프리팹을 사용해 컴파일, 여섯 컷 전환, 엔진 전개 중 화면 범위, 카메라의 차체 밖 배치, 체크포인트 위치·시선 고정, 거리별 풍압 감쇠, 일시정지·재시작·진동 끄기를 확인했습니다. 결과는 `six-camera-validation.txt`에 기록합니다. 기존 네 컷의 설정과 오브젝트 ID도 보존했습니다. 실제 조명·지형을 모두 포함한 최종 영상의 가림과 GPU VFX 미관은 본 씬에서 확인해야 합니다.
