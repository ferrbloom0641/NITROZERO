# RH_racing 자동 레이싱

## 실행

Unity에서 `Assets/01RAEHYEON/RHScenes/RH_racing_Autonomous.unity`를 열고 Play를 누릅니다.
기존 RH_racing의 차량 6대와 환경을 복제한 별도 씬입니다. 원본 씬 및 차량 프리팹 자산은 수정하지 않습니다.

- Play 시 기존 대형 이동과 Timeline 제어를 중지하고 각 차량이 주행을 시작합니다.
- 목표 속도는 240~300km/h입니다. 앞차와의 간격 유지, 도로 끝 정지에는 이보다 낮은 속도를 허용합니다.
- 도로 메시의 양쪽 가장자리를 읽어 약 5.37km 경로와 실제 폭을 계산합니다.
- 장착 부품을 포함한 차량 크기를 측정합니다. 현재 차량 구성은 2열로 운행하며, 공간이 확보될 때 추월합니다.
- 바퀴 회전은 실제 이동 거리, 조향은 도로 굴곡과 차선 변경에 연결됩니다.
- 열린 도로 끝에서는 감속 후 정지합니다. 처음으로 순간이동하지 않습니다.

## 촬영과 조정

화면 왼쪽 위에서 Pause/Resume, Restart와 Wide/Chase/Top 카메라를 선택합니다.
촬영 전 Hide controls를 누르면 표시가 사라집니다. Hierarchy의 `Autonomous Race - 6 Cars`에서 Show Controls를 다시 켤 수 있습니다.

동일 초기 설정의 Restart는 같은 주행 결과를 재현합니다. 기존 Timeline을 스크럽하는 방식은 지원하지 않습니다.
차량별 Preferred Speed Kph, Following Gap, Lane Change Speed는 해당 오브젝트의 Inspector에서 조절할 수 있습니다.
기존 카메라를 사용하려면 Play 전에 Create Preview Camera를 끕니다. 그 경우 기존 카메라 경로를 주행에 맞게 별도로 연결해야 합니다.

이 구현은 도로 경계를 이용해 위치를 제어하는 촬영용 자율주행입니다. 타이어 물리 기반 레이싱, 임의 장애물·미사일 회피, 도로 분기 선택은 포함하지 않습니다.

## 부드러운 조향 보완

- 차선 변경의 횡이동 속도가 즉시 켜지거나 꺼지지 않도록 가속·감속을 완만하게 처리합니다.
- 도로 방향을 앞뒤 24m에서 확인하고, 차체 회전에 0.4초 응답과 초당 28도 상한을 적용합니다.
- 앞바퀴 조향도 0.25초에 걸쳐 부드럽게 변화합니다. 속도가 낮아져도 갑자기 차체가 옆을 향하지 않습니다.
- 위치·차체 회전·앞바퀴 각도·카메라 진행 거리를 같은 프레임 시점으로 보간합니다. 일시정지 시에도 보간 상태를 유지합니다.
- Inspector의 Smooth Driving에서 Lane Change Response(기본 1.1), Heading Sample Distance(24), Steering Response(0.4), Max Yaw Speed(28), Wheel Steering Response(0.25)를 조절할 수 있습니다.
- 변경을 확인할 때는 Play를 종료한 뒤 다시 시작합니다. 기존 주행 상태의 중간부터 이어지는 결과와 비교하지 않습니다.

회전 보완 검사는 실제 도로 메시와 기존에 측정한 6대의 차체 크기를 사용한 별도 Unity 시뮬레이션입니다. 회전 속도·회전 가속도, 차선 변경 가속도, 차량 간 공간, 재시작 시 조향 재현성, 반복 렌더링 시 상태 불변성을 검사합니다. 수정 후 실제 차량의 영상 체감은 촬영 화면에서 추가 확인해야 합니다.

## 레이싱 라인·추월 단계·운전 성향

현재 도로에서 긴 우회전 1개를 자동 감지합니다. 진입 전 바깥으로 준비하고, 코너 안쪽을 지나 탈출 시 다시 바깥으로 펴는 주행선을 사용합니다. 옆 차량이나 추월 경로가 우선하므로 혼잡한 상황에서는 이상적인 주행선 진입을 기다립니다. Inspector의 Use Racing Line으로 이 기능을 켜고 끌 수 있습니다.

추월은 `주행 → 추월 준비 → 옆 차선 진입 → 추월 중 → 주행선 복귀 → 재정비` 순서입니다. 앞차보다 충분히 앞선 뒤 안전한 복귀 공간을 확인합니다. 공간을 확보하지 못하거나 시간이 지나면 시도를 취소하고 재정비합니다. 순위가 바뀐 횟수와 안전한 복귀까지 완료한 추월 횟수는 다릅니다.

| 차량 | Driving Style | 주행 차이 |
|---|---|---|
| 파랑 | Balanced / 균형형 | 적당한 간격과 추월 준비 시간 |
| 카키 | Patient / 안정형 | 넉넉한 간격, 긴 준비 시간, 완만한 차선 변경 |
| 흰색 | Precise / 정밀형 | 큰 차체에 맞춘 여유 간격, 신중한 추월 |
| 빨강 | Attacker / 공격형 | 짧은 준비 시간, 적극적 추월과 가속 |
| 노랑 | Opportunist / 기회 포착형 | 빠른 빈 차선 판단과 추월 기회 활용 |
| 연두 | CornerSpecialist / 코너 특화형 | 코너 안쪽을 더 늦게 통과하고 도로 폭을 더 넓게 활용 |

`Autonomous Race - 6 Cars > Racers > Driving Style`에서 차량별 성향을 변경합니다. 성향은 최고 속도만 바꾸는 설정이 아닙니다. 준비 시간, 목표 간격, 차선 변경 속도, 가속, 코너 속도와 안쪽을 통과하는 위치가 달라집니다. 모든 성향에 공통 안전거리와 300km/h 상한을 적용합니다.

화면 표시에는 차량별 성향과 현재 추월 단계가 나옵니다. Max Lateral Acceleration의 기본값은 3m/s²로, 추월 취소나 주행선 복귀 시에도 좌우 움직임이 갑자기 바뀌지 않게 제한합니다.

`race-tactics-validation.txt`는 실제 도로와 측정 차체 크기로 실행한 120초 시뮬레이션 결과입니다. 6대 주행 및 추월·복귀 단계, 준비 시간, 대상 상실 시 취소, 안전거리, 끝 지점 정지, 재시작 재현성과 급격한 회전을 검사했습니다. 교통이 없는 별도 코너 검사에서는 안정형·코너 특화형 모두 바깥→안쪽→바깥 궤적을 실제로 주행했고, 코너 특화형은 안쪽 통과 지점이 약 57m 더 늦고 횡방향 사용 폭이 더 컸습니다. 영상의 체감과 녹화 성능은 실제 씬에서 Play를 재시작해 확인합니다.

## 검증

`Tools > Trailer > Validate Autonomous Race`는 별도 임시 미리보기 씬에서 실제 차량 6대로 120초를 시뮬레이션합니다.
현재 열린 작업 씬을 전환하거나 저장하지 않습니다. 속도 상한, 도로 폭, 차량 간 공간, 추월, 도로 끝 정지, 재시작 재현성을 확인합니다.
결과는 같은 폴더의 `unity-validation.txt`, 15/30초 화면은 `preview-15s.png`, `preview-30s.png`에 기록합니다.
실시간 녹화 프레임 성능은 녹화 해상도와 프로젝트의 렌더링 설정에 따라 별도 확인이 필요합니다.
