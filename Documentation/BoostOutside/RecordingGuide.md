# RH_boostOutside 외부 부스터 촬영

씬: `Assets/01RAEHYEON/RHScenes/RH_boostOutside.unity`

Hierarchy의 `BOOST OUTSIDE - 11 Recording Cameras`에 최종 빨간/파란 부스터 차량 프리팹, 출력 카메라, Cinemachine 카메라 11개가 들어 있다. 기존 `BoostRun_ParallelFormation`과 기존 Main Camera는 비활성 상태로 보존했다. 원본 프리팹과 다른 씬은 수정하지 않았다.

## 녹화

1. 씬을 열고 Play한다. 자동으로 28초 주행을 시작한다.
2. Game 창에 포커스를 두고 **F1–F11**로 카메라를 고른다. 카메라 선택은 주행 시간을 바꾸지 않는다.
3. **R**로 처음부터 같은 주행을 반복하면서 원하는 카메라를 녹화한다.
4. **Space**는 주행 시퀀스 재생/일시정지다. **H**는 조작 패널 표시/숨김이다. 기본값은 숨김이며 녹화 전에 숨긴다.
5. 원하는 장면 근처에서 시작하려면 패널이나 Inspector의 **Cue selected shot**을 누른다. 해당 컷의 기준 시점 2초 전으로 이동하고 정지한다. Space로 재생한다. 입자 이펙트까지 충분히 예열하려면 R로 처음부터 재생하는 방법을 권장한다.

Unity Recorder는 `Main Camera - Boost Outside Output`을 대상으로 지정한다. 컷 사이의 자동 편집은 하지 않는다. 선택한 카메라를 유지하므로 각 카메라의 영상을 따로 녹화하고 프리미어에서 필요한 부분을 자르면 된다. 16:9 구도로 검수했다.

## 조정

### 구도별 일괄 녹화

`RH_boostOutside` 씬에서 **Tools → Boost Outside → 구도별 일괄 녹화**를 연다. Director Inspector의 **구도별 일괄 녹화…** 버튼으로도 열 수 있다.

기본 설정은 **1920×1080 / 30fps / MP4 H.264 High / 오디오 포함**이다. **모든 구도 녹화 시작**을 누르면 Play 진입부터 11개 구도의 전체 테이크 녹화까지 자동으로 진행한다. 각 구도는 0초부터 같은 동작과 흔들림으로 시작한다. 고정 프레임 간격으로 진행하므로 컴퓨터가 느려도 영상의 재생 속도는 유지되며 실제 녹화에 더 오래 걸릴 수 있다. Game 뷰를 열어 두고 녹화 중 씬이나 Inspector 값을 바꾸지 않는다. 카메라 전환·재시작 단축키와 안내 오버레이는 녹화 중 차단된다.

저장 위치는 프로젝트의 `Recordings/BoostOutside/날짜_시간/`이다. `01_구도이름.mp4`부터 구도별 파일과 `takes.tsv` 목록을 만든다. 기본 28초 테이크는 파일당 840프레임이며 총 11개 영상이다. 프리미어프로에 MP4 파일들을 함께 가져오면 된다. 새 녹화는 새 폴더를 사용한다. **녹화 중단** 시 완료된 파일은 유지하고, 녹화하던 파일은 가능한 범위에서 마무리한다. Edit 모드에서 시작했으면 완료 후 Edit 모드로 돌아간다. **저장 폴더 열기**로 결과를 확인한다.

`Boost Outside Director` Inspector:

- `Selected Shot`: 0부터 10까지 카메라 선택.
- `Camera Motion`: 미세한 엔진 진동, 속도에 따른 풍압, 짧은 점화 충격을 켜고 끈다. `Camera Motion Intensity` 기본 1, 더 차분하게 찍으려면 0.5. 근접 구도는 약하게, 추격 구도는 조금 더 강하게, 도로 옆 고정 카메라는 통과 풍압 위주로 적용한다. 흔들림은 테이크 시간 기준이므로 정지·재녹화·시점 이동 시 재현된다. 최대 위치 변화 6cm, 회전 0.35도로 제한한다.
- `Time`: 재생 시점. Edit 모드에서는 수정 후 `Apply current time / camera`로 미리본다.
- `Shots`: 카메라별 Offset, Aim, Cue. 좌표는 차량 크기 배율과 무관한 미터 단위이며 X=진행 방향 기준 오른쪽, Y=위쪽, Z=전방이다. 일반 샷은 차량 루트 기준, 고정 샷은 도로 기준이다.
- 화각은 각 `CM_...`의 Cinemachine Camera → Lens에서 조정한다.
- `Initial Gap`: 파란 차의 시작 리드 거리. 기본 42m.
- `Lane Offset`: 기본 6m. 좌우 차선 중심 간격은 12m다.
- `Red Deploy At`=2초, `Blue Deploy At`=9초, `Deploy Duration`=3.2초.
- `Draw Level At`=20초, `Take Duration`=28초.
- `Cruise Speed`=135m/s(486km/h), `Boost Speed`=255m/s(918km/h). 직전 설정의 2배이며 빨간 차는 간격을 좁히는 동안 조금 더 빠르다. 전개·병주 시점과 28초 테이크는 그대로 유지한다. 28초 이동 거리는 5,526m, 종료 위치는 X=-2,826m다. 고정 카메라 위치는 새 속도의 Cue 시점 거리로 자동 계산된다.
- 도로 기준점은 `(2700,-23.65,0)`, 진행 방향은 월드 -X다. 카메라는 지형 높이를 확인해 최소 0.5m 위에 둔다.

카메라 Transform은 재생 중 Director가 제어한다. 위치를 바꿀 때는 해당 Shot의 Offset/Aim을 조정한다. 부스터의 외장 변형은 기존 컨트롤러의 진행도 API로 평가하고, 바퀴도 누적 주행 거리로 평가한다. 두 차량은 도로에 맞춰 전개 상태의 폭이 최대 약 10m가 되도록 씬 인스턴스의 배율을 조정했다. 재시작과 시점 이동에서 차량 위치와 기구 자세가 재현된다.

## 검증 범위

### 파란 차 불꽃 꼬리·속도 수정 (2026-09-17)

파란 차의 `ApplyTransformationProgress`가 매 프레임 `SetFxActive(true)`를 호출하면서 ParticleSystem.Clear와 VisualEffect.Reinit도 매번 실행하고 있었다. 이미 활성 상태인 이펙트는 초기화하지 않도록 변경했다. 점화 전환에서만 시작하고 소화 전환에서만 정리하며, 부모가 꺼져 있는 경우에는 다시 활성화한다. 순항·부스트 속도를 모두 1.5배로 높였고 트랙사이드 카메라의 통과 위치도 새 속도에 맞췄다.

### 접지·초점 수정 (2026-09-17)

초기 배치에서 회전된 타이어의 경계 상자를 사용해 실제 타이어 표면보다 큰 반경을 계산했다. 실제 메시 꼭짓점과 노면 Y=-23.65를 측정해 빨간 차를 0.477711m, 파란 차를 0.634381m 낮췄다. 저장된 차량 위치와 Director의 높이 값을 함께 수정해 Play 중에도 보정이 유지된다. 28초 동안 57개 시점에서 8개 타이어의 실제 표면을 검사했으며, 기존 앞뒤 바퀴 높이 차이를 유지한 접지 간격은 약 -0.7mm~28.7mm다.

Global Volume은 이 씬 전용 `BoostOutsideVolumeProfile`을 사용한다. 기존 헬멧용 프로필의 Bokeh Depth of Field(초점 2m, F/2, 40mm)가 원거리 차량을 흐리게 만들고 있었으므로 전용 프로필에서 Depth of Field만 비활성화했다. Bloom과 톤매핑은 유지하고 원본 HelmetVolumeProfile은 수정하지 않았다.

분리된 Unity 6000.3.18f1 프로젝트에서 실제 차량 메시를 사용해 11개 구도를 렌더링하고 확인했다. 검수 이미지는 재질을 단색으로 대체한 구도 확인용이다. 최종 씬에는 원래 프리팹의 재질·VFX 연결이 유지된다. 실제 씬의 최종 조명, Bloom 및 GPU 분사 이펙트의 합성 화면은 별도 검수가 필요하다.

검증 결과와 백업 경로는 같은 폴더의 `validation.txt`, `play-validation.txt`, `installation.json`을 참고한다.
